# Calculadora de Final de Fisiologia

Aplicativo HTML estatico para calcular la nota minima necesaria en la Final de Fisiologia segun:

- Parcial 1: 0 a 100
- Parcial 2: 0 a 100
- Entregas 1 a 4: 1 a 10
- Ateneo oral: 1 a 30
- Tarea Academica: 30% entregas + 70% Ateneo oral
- Promedio global: 60% Media Parcial + 40% Final

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube el archivo `index.html` en la raiz del repositorio.
3. Entra en `Settings > Pages`.
4. En `Build and deployment`, selecciona `Deploy from a branch`.
5. Elige la rama `main` y la carpeta `/root`.
6. Guarda y espera el enlace de GitHub Pages.

El enlace queda parecido a:

```text
https://tuusuario.github.io/nombre-del-repositorio/
```
